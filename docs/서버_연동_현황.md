# 서버 연동 현황 (Backend/wow_server.py ↔ web-client)

사용자 id 는 서버의 **playerId** 입니다 (프로필 · 덱 · 친구 · 전적 모두 playerId 기준). 오류 문구는 서버가 주는 `message` 를 그대로 보여줍니다.

## 연결됨 (실제 서버 호출)
| 화면 | 기능 | 서버 API |
|---|---|---|
| 로그인·가입 | 이메일 로그인 · 가입 · 구글 로그인 · 로그아웃 · 비밀번호 재설정 요청 · 닉네임 중복 확인 · 세션 복원 | `/api/auth/login` `register` `google` `logout` `password-reset` `nickname-available` `me` |
| 로비·마이페이지 | 프로필(레이팅·승패) · 전적 목록 · 닉네임 변경 | `/api/players/{id}` `/api/matches/player/{id}` `PUT /api/players/me` |
| 마법서 | 덱 불러오기·저장 (서버가 8장·중복·존재 여부 검증) | `GET·PUT /api/decks/me` |
| 결과 | 전투 종료 시 전적 기록 → 레이팅 반영 | `POST /api/matches` |
| 랭킹 | 상위 100명 | `/api/players/ranking` |
| 친구 | 목록 · 요청 · 수락/거절 · 삭제 · 접속 상태 | `/api/friends` `requests` `respond` `player/{id}` `/api/presence/*` |
| 우편 | 우편·공지·초대 목록 · 읽음 · 초대 보내기 | `/api/mailbox` `read` `/api/mails/invite` |

## 아직 앱 안의 시뮬레이션 (서버 API 는 준비돼 있음)
| 화면 | 지금 | 연결할 서버 API |
|---|---|---|
| 랭킹전 매칭 대기 | 15초 타이머로 흉내 | `POST·GET·DELETE /api/matchmaking/queue` `status` |
| 친선전 룸 | 방 코드·게스트·봇 채우기를 앱 안에서 흉내 | `/api/rooms` `{code}` `join` `ready` `start` `leave` `kick` |
| 전투 | 앱 안의 규칙 시뮬레이터 (Photon 서버 판정이 아님) | `/api/match/{id}/join` `result`, 시전 신호 `/api/spells/cast` |

## 서버 동작에서 알게 된 것
- **새 플레이어는 기본 덱 8장을 받습니다** → 가입 직후에도 마법서에 덱이 채워져 있습니다.
- **시작 레이팅은 1200** 입니다. 앱의 등급 이름(`숙련 마법사` 등)은 1000 시작 기준으로 만들어서, 신규 유저가 `숙련 마법사`로 보입니다. 등급 구간을 정해야 합니다.
- 서버는 **무승부(DRAW)** 도 기록합니다 → 마이페이지 전적에 `D`/`DRAW` 로 표시하게 했습니다.
- 로그인 실패는 **HTTP 400** 입니다 (401 이 아님). 401 은 "토큰 없음/만료"에만 씁니다.
- 서버 우편에는 `reward` · `claimed` 필드가 있지만, 기획서 §23.1(우편함에 보상·아이템 없음)에 따라 앱은 표시하지 않습니다.
- 서버의 스킬 19종은 **이름 · 등급 · 쿨타임이 앱 데이터와 모두 일치**합니다 (S12 = 드래곤).
- 관리자 계정(`admin@wow.dev`)은 플레이어가 없어 이 앱에서는 로그인되지 않습니다 (관리자 콘솔 `#/admin` 사용).
