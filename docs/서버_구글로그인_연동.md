# 구글 로그인 연동 (Backend/wow_server.py)

```
[Google 계정으로 계속하기]
  1) GET  /api/auth/config            → { googleClientId, googleEnabled }
  2) 구글 팝업에서 access_token 받기     (Google Identity Services)
  3) POST /api/auth/google  { "accessToken": "<구글 access_token>" }
        → { accessToken(서버 JWT), userId, email, role, playerId, nickname }
  4) 이후 모든 API 에  Authorization: Bearer {JWT}   (토큰 키: localStorage `wow.spring.token`, 서버 웹 화면 · Unity WebGL 과 같은 키)
```
- 코드: `src/lib/serverApi.ts` · 서버: `Backend/wow_server.py` (`/api/auth/google`, `verify_google_token`)
- **서버는 클라이언트 ID 만 필요합니다. Client Secret 은 필요 없습니다** (서버가 구글에 토큰을 직접 물어 `aud` 가 우리 클라이언트 ID 인지만 확인). Secret 은 어디에도 넣지 마세요.
- 처음 로그인한 구글 계정은 서버가 계정과 플레이어를 자동으로 만듭니다 (닉네임은 구글 이름 기준).

## 1. 클라이언트 ID 를 서버에 넣기 (서버를 실행하는 PC 에서)
셋 중 하나 (위에서부터 우선):
1. 환경변수 `GOOGLE_CLIENT_ID`
2. **`Backend/google_client_id.txt` 첫 줄** ← 권장 (`#` 로 시작하는 줄은 무시)
3. 관리자 콘솔 → 게임 설정 → `auth.google_client_id`

```text
<숫자>-<문자열>.apps.googleusercontent.com      ← 구글 콘솔에서 만든 클라이언트 ID 한 줄
```
`Backend/google_client_id.txt` 는 `.gitignore` 에 들어 있어 **커밋되지 않습니다.** 서버를 켜는 PC 마다 만들어 두세요.

## 2. 구글 클라우드 콘솔 확인
- OAuth 클라이언트 유형: **웹 애플리케이션**
- **승인된 JavaScript 원본**: `http://localhost:8080` (서버 웹 화면), `http://localhost:8443` (이 React 앱). 다른 주소로 열면 그 주소도 추가
- 대상이 "테스트" 상태면 **테스트 사용자**에 로그인할 구글 계정 추가
- 만든 직후에는 적용에 5분~몇 시간 걸릴 수 있습니다

## 3. 실행 순서
1. 위 1번대로 ID 파일을 만든다
2. `Backend/run_server.bat` 실행 (또는 `python Backend/wow_server.py`)
3. 브라우저에서 http://localhost:8080/api/auth/config → `"googleEnabled":true` 인지 확인
4. `Backend/web-client` 에서
   ```powershell
   Copy-Item .env.example .env
   npm install
   npm run dev
   ```
5. http://localhost:8443 → **Google 계정으로 계속하기**
   (서버의 웹 화면 http://localhost:8080 도 같은 ID 로 로그인됩니다)

`.env` 는 `VITE_API_BASE=` (빈 값 = 같은 주소) 와 `API_TARGET=http://localhost:8080` 두 줄이면 됩니다. 서버가 다른 PC 면 `API_TARGET=http://<그 PC IP>:8080`.

## 문제 해결
| 증상 | 원인 | 해결 |
|---|---|---|
| "서버에 구글 클라이언트 ID 가 아직 없습니다" | `/api/auth/config` 가 `googleEnabled:false` | 위 1번 후 **서버 재시작** |
| 구글 팝업에서 `origin_mismatch` | 접속한 주소가 "승인된 JavaScript 원본"에 없음 | 위 2번 |
| "이 앱은 확인되지 않았습니다 / 액세스 차단" | 콘솔 "테스트" 상태 + 테스트 사용자 아님 | 테스트 사용자 추가 |
| "다른 앱용으로 발급된 Google 토큰입니다" | 서버의 ID 와 팝업이 쓴 ID 가 다름 | 서버의 ID 파일 확인 |
| "Google 확인 서버에 연결하지 못했습니다" (502) | 서버 PC 가 인터넷에 연결 안 됨 | 서버 PC 인터넷 확인 |
| "서버에 연결할 수 없습니다…" | 서버 꺼짐 · `API_TARGET` 틀림 · `.env` 수정 후 재시작 안 함 | 서버 확인, `npm run dev` 재시작 |
| 팝업이 차단되었습니다 | 브라우저 팝업 차단 | 팝업 허용 |
| 관리자 계정으로 로그인하면 "플레이어 정보가 없습니다" | 관리자는 플레이어가 아님 | 관리자 콘솔 `#/admin` 에서 로그인 |

## 검증 현황
- ✅ 자동 테스트: 실제 서버를 띄워 로그인·가입·덱·전적·랭킹·친구·우편·접속 상태를 끝에서 끝까지 확인, 구글 흐름은 서버 응답 형식을 따른 가짜 서버로 확인
- ✅ 실제 브라우저 + 실제 서버(프록시 포함)로 로그인 → 로비 → 마법서 → 랭킹 화면 확인
- ✅ 위 클라이언트 ID 를 서버에 넣으면 `/api/auth/config` 가 `googleEnabled:true` 로 응답하는 것 확인
- ❌ **실제 구글 팝업 → 실제 구글 토큰 검증은 확인하지 못했습니다** (개발 환경에서 구글에 접속할 수 없음). 첫 실제 로그인에서 오류가 나면 위 표의 문구와 비교해 알려주세요.
