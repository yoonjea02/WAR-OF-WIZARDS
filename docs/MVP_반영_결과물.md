## 4. UI 통합 — HUD 필드 대응표

Unity MVP HUD(스크린샷)와 내 React HUD의 대응입니다. "MVP에 없음"은 서버/Unity가 값을 내려줘야 화면에 쓸 수 있는 항목입니다.

| Unity MVP HUD 표시 | 의미(스크린샷 기준 해석) | React HUD 필드 | 비고 |
|---|---|---|---|
| `YOU 1000/1000` · `1000/1000 ENEMY` | 양측 HP | `me.hp/maxHp` · `foe.hp/maxHp` | |
| `00:01` | 경과 시간 | `t` | |
| `S0` · `up 4:59` | 강화 단계, 다음 강화까지 *(추정)* | `phase` · `nextPhaseIn` | 의미를 팀에서 확인 필요 |
| `T:O N:O` | 타워·넥서스 상태, O = 생존 *(추정)* | `tower` · `nexus` (체력 바) | MVP는 O/X만 표시 |
| `dmg 20%` | 받는 피해 비율 | `takeRatio` | |
| `regen` | HP 회복 활성 | `regen` (다음 회복까지 초) | |
| `ATK x1.00` | 공격 배율 | `atkMul` | |
| `Next wave 4s` | 다음 웨이브까지 | `nextWaveIn` | 이번에 추가 |
| `POS L [C] R` | 내 위치(열) | `me.col` | |
| `1. S03 Fireball` … | 슬롯 번호·스킬 | `slots[]` | MVP는 영문 표기 |
| `FIGHT!` | 시작 배너 | 카운트다운 `START!` | |
| `Fireball [|||..]` | 조준 중 표시(포인팅 유지 진행도로 *추정*) | — | 의미 확인 필요 |
| (없음) | — | 타워/넥서스 **체력 수치**, 유닛 수, 상태효과, 이벤트 로그, 쿨타임 남은 시간, 고위력 남은 횟수 | **서버가 내려줘야 할 값** |

### 확인이 필요한 점
1. **마법진 그림 오류/중복**: S06 번개의 마법진이 토네이도입니다(S05와 같은 모티프). S09·S13·H06은 모두 탑 모양, S08·H04는 방패+별로 거의 구분되지 않습니다. 플레이어가 슬롯에서 스킬을 구별해야 하므로 수정이 필요해 보입니다.
2. **여러 획 룬이 10개**: 눈, 화살, 가로선 5개, #, X, 모래시계, 별표, 하트, 반사 결계, 화난 얼굴 등은 한 번의 핀치로 이어 그리기 어렵습니다. MVP는 핀치 한 번으로 그리는 것으로 보이는데, 여러 획 입력을 허용하는지(손을 뗐다가 다시 핀치하는 시간 제한 등) 확인이 필요합니다. *(획 수는 추정)*
3. **MVP 임시 룬과 최종 룬이 다릅니다**: 파이어볼 동그라미 → 왕관, 총난사 Z → 가로선 5개, 쉴드 역삼각형 → 방패. 이 셋을 먼저 바꿔 인식률을 보는 것을 권합니다.
4. **마법진 해상도가 낮습니다**: 원본이 가로·세로 약 90~145px이라 큰 화면이나 VR에서는 흐릿합니다. 원본 파일이 필요합니다.

### 서로 비슷한 룬 후보 (참고용)
룬 그림을 가늘게 줄여 점 집합으로 만든 뒤 거리를 계산했습니다(방향 유지, 거리가 작을수록 비슷, 전체 171쌍의 중앙값 0.219).

| 쌍 | 거리 |
|---|---|
| H01 프리즈 ↔ H05 분노 | 0.111 |
| H05 분노 ↔ H06 소환탑 | 0.121 |
| S06 번개 ↔ H04 반사 결계 | 0.124 |
| S03 파이어볼 ↔ H06 소환탑 | 0.130 |
| S09 타워 버프 ↔ S11 도끼 전사 | 0.139 |

- 눈으로 봐도 납득되는 쌍: **프리즈↔분노**(원 + 안쪽 도형), **파이어볼↔소환탑**(지붕 모양), **타워 버프↔도끼 전사**(교차하는 선)
- 숫자만 가깝고 눈으로는 구분되는 쌍: 번개↔반사 결계, 분노↔소환탑
- 우려했지만 수치상 가깝지 않았던 쌍: **X(도끼 전사)↔별표(레이저 빔)** 는 171쌍 중 130위, **아래 화살표(화살 세례)↔위 화살표(집중)** 는 89위(회전을 무시해도 144위)였습니다. 모양이 일부 겹쳐 보여도 이 근사에서는 비슷하다고 나오지 않았습니다.
- **한계**: 실제 인식기($P+)가 아니라 이미지 근사입니다. ㅊㄱㅇ의 유사도 매트릭스(W5)를 대체하지 않고, 먼저 볼 후보를 좁히는 용도입니다.

## 6. 값이 확정되면 바꿀 위치

"확정 필요"로 적힌 수치는 전부 제가 임시로 둔 값입니다. 코드 숫자는 HP 600 기준이고, 실행 시 `HP_SCALE`(= HP ÷ 600 = 1.67)이 곱해집니다. 수치를 확정할 때는 **HP 1000 기준 숫자를 그대로 넣고 `HP_SCALE`을 1로 두면** 됩니다.

| 항목 | 위치 | 코드 숫자 | HP 1000 기준 실제 적용 |
|---|---|---|---|
| 파이어볼 S03 | `battleSim.ts` | 14 | 약 23 |
| 화살 세례 S04 | 〃 | 8 | 약 13 |
| 토네이도 S05 | 〃 | 6 | 10 |
| 번개 S06 | 〃 | 16 | 약 27 |
| 총난사 S07 | 〃 | 12 | 20 |
| 레이저 빔 H02 / 흡혈 H03 | 〃 | 30 / 12 | 50 / 20 |
| 독 장판 S02 | 〃 | 초당 3 (6초) | 초당 5 |
| 방어 쉴드 S08 | 〃 | 흡수 20 (8초) | 약 33 |
| 타워 / 넥서스 체력 | `rules.ts` | 300 / 500 | 그대로 |
| HP 회복량(10초마다) | `rules.ts` | 33 | 33 |
| 5분 강화 폭 | `rules.ts` | 쿨타임 -10% · 공격력 +10% | 그대로 |

타워 생존 시에는 위 피해가 **20%만** 들어갑니다(명세서).

```
src/assets/skills/circle/S01.png ~ H06.png   마법진 (정사각형 권장, 256px 이상)
```

룬은 흰 획·투명 배경이어야 스킬 색으로 칠해집니다. 파일이 없는 스킬은 기본 도형 아이콘으로 자동 대체됩니다. 바꾼 뒤 `npm test`를 돌리면 19종이 모두 연결됐는지 확인됩니다.

## 9. 한계 · 확인하지 못한 것
